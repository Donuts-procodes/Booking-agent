🔗 COMMON API CALLS:
═════════════════════════════════════════════════════════════════════════════

Get All Cars:
  GET /api/cars

Get Single Car:
  GET /api/cars/CAR-004

Search by Brand:
  GET /api/cars?brand=Tata

Search by Price Range:
  GET /api/cars?min=500000&max=1000000

Create Booking:
  POST /api/bookings
  {
    "customer_name": "John Doe",
    "customer_email": "john@example.com",
    "customer_phone": "9876543210",
    "car_id": "CAR-004",
    "query_type": "Test Drive Request",
    "message": "I want to test drive"
  }

Get Booking Status:
  GET /api/bookings/TICKET-2024-01-15-0001
